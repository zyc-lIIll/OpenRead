# Annotation UI（未实现）

这是目标模块，负责选区入口、统一浮窗聊天、便签和讨论恢复。当前尚无 Annotation 浮窗、摘要/便签 UI 或 Agent 问答；基础聊天和 PDF 选区接口还未连接起来。

目标上下文可以是选中文字或整条公式、PDF/PPT 当前页，或 PDF 框选区域。整页和框选入口可从 PDF 页面菜单发起；框选后把截图预览在输入框上方，用户可以移除截图再发送。浮窗聊天复用 `../chat_ui`。

目标行为还包括：浮窗锚点与屏幕位置分开管理；讨论可关闭后恢复，回复可继续追问；便签区分 `comment` 和 `question`，但无需用户预先分类。批注关系和持久化由 `desktop/backend/annotation/` 负责，相关 Agent 与 UI 均未实现。
