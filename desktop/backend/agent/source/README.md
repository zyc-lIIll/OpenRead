# Agent Source 上下文

该目录负责 Agent 按文件格式获取、定位和切分上下文，不负责导入或底层解析。底层文件管理和解析接口仍放在 `desktop/backend/source/`；PDF 页面文字与图像由现有 PDF.js 解析桥接提供。

当前只实现 `pdf.rs`。它按 PDF 实际页序组合文字和对应页图，按不超过 12,000 个 Unicode 字符、最多 8 个页面图像切分。没有文字层的页面仍会带上页面图像。页面 PNG 最长边不超过 2,048 px，单页数据上限为 4 MiB。图片和文字作为同一轮模型输入发送。

模型可在页边界建议下一段连续页码。后端只接受从第一未读页开始且不超过 8 页的建议；缺少或无效时使用程序默认切分。模型明确拒绝图像输入、请求体过大或单页图像无法读取时，尽可能回退到文字，并在初始化说明中列出受影响页码。若最后一段完全不可读，最终概览会注明未纳入的页码。当前不做本地 OCR。

后续格式开始实现时，再按需新增 `markdown.rs`、`word.rs`、`ppt.rs` 等独立模块，不放空占位文件。
