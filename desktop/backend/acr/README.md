# ACR 后端读写

`desktop/backend/acr/` 是未来 `.acr` 档案导入、导出和校验的后端归属。格式结构、对象关系和兼容目标由顶层 [ACR 草案](../../../ACR/README.md) 说明。

当前目录没有读写实现或子模块。产品目标采用 ZIP + JSON 容器，涵盖 Source 原件、Explanation、Annotation 讨论及其关系、稳定锚点和阅读附件。账号凭据与 API Key 不得进入档案。

实现读入时需校验容器、格式版本、路径、引用关系并限制解包大小。写入失败时保留已有文件。正式格式发布后，以公开样例验收导出、干净环境重开和独立阅读器兼容性。
